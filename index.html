AI-Powered Car & Insurance Information Platform

Project Overview

The AI-Powered Car & Insurance Information Platform empowers users to search car details, compare models, and estimate insurance premiums using AI. The system uses LLMs such as OpenAI's ChatGPT or Mistral to provide intelligent, natural-language responses tailored to user needs.

My Contribution: I worked on building the core Flask API, implementing LLM integration for car and insurance queries, building comparison logic, and refining the chatbot interaction for follow-up queries. I also contributed to the UI using Tailwind CSS and ensured the responses were user-friendly and informative.

Sprint Objectives Summary

Sprint Objective Outcome
Sprint 1 MVP Backend Setup: Implement basic Flask routes for car queries and OpenAI integration. Completed initial endpoints for car searches with working LLM responses.
Sprint 2 Develop Comparison and Insurance Logic: Add multiple car input handling and insurance estimate flow. Built comparison engine, added structured AI prompts, and created insurance estimator.
Sprint 3 Build Chatbot & Follow-up Handling: Enable AI-driven chatbot interface with memory. Integrated chatbot flow with query memory and dynamic response support.
Sprint 4 Finalize UI & System Testing: Tailwind-based UI, formatting, testing, and responsiveness. Completed UI design, added test cases, and finalized formatting and performance tuning.
